# 요구사항

## 1. 프로젝트 목적

학생이 클라우드 VM 신청, Tailscale 연결, VM 접속, 서비스 배포 과정을 안내 문서만 보고 수행할 수 있는 정적 웹사이트를 제공한다.

## 2. 사용자

- 학생: VM을 신청하고 할당받아 서비스를 배포하는 사용자
- 운영진: 신청서를 이메일로 접수하고 Tailscale 초대와 VM 생성을 수행하는 관리자

운영진용 관리 기능은 웹사이트 범위에 포함하지 않는다.

## 3. 범위

### 포함

- 서비스 소개와 이용 조건
- 신청서와 사용 결과 보고서 다운로드
- 두 양식의 항목별 작성 및 제출 시점 안내
- 이메일 제출 방법과 문의처
- Tailscale 설치 및 로그인 안내
- 운영진 초대 링크 수락 방법
- Tailscale 연결 상태 확인 방법
- VM 생성 완료 후 접속 방법
- 서비스 배포 절차
- `http://학번.dauswc.org` 주소 확인 방법
- 자주 묻는 질문과 장애 해결 안내
- 데스크톱 및 모바일 화면 지원

### 제외

- 웹 신청서 작성 및 제출
- 이름, 학번, 전화번호, 이메일 등 개인정보 수집
- 회원가입과 로그인
- 신청 상태 조회 및 관리자 승인 화면
- VM 자동 생성
- 문자 메시지 또는 유료 알림
- Tailscale 초대 링크의 공개 게시

## 4. 신청 정책

신청서에는 기존 양식의 다음 정보가 포함된다.

- 지원자 정보: 소속 대학, 학과, 이름, 학번, 휴대전화, 이메일
- 플랫폼 지원 유형: AI 인프라, 클라우드 서버, 데이터/모델, 오픈소스, 교육 콘텐츠, AI·SW 실습실, 기타
- 활용 프로그램: AI·SW 실습 교과목, 산학 협력 프로젝트, 기초 교육 프로그램, 성과 확산 프로그램, 학생 개인 프로젝트, 기타
- 활용 내용: 교과목명, 활용 목적, 프로젝트 주제, 프로젝트 내용

클라우드 서버의 기본 신청 기준:

- 메모리: 1 GB
- 디스크: 10 GB
- 시작일: 신청일
- 종료일: 신청일로부터 3개월
- 무기한 사용: 별도 요청 가능
- VM ID: 신청자 학번
- 운영체제: Ubuntu Linux
- 학생 서비스 포트: 8080
- 그 외 서버 사양: 운영 정책의 기본값 적용

## 5. 사용자 여정

양식 및 담당자:

| 구분 | 저장소 경로 또는 연락처 |
| --- | --- |
| VM 신청서 | `site/public/forms/vm-application.hwp` |
| 사용 결과 보고서 | `site/public/forms/vm-usage-report.hwp` |
| 신청서 접수 및 VM 운영 문의 | DevWorks 운영진 `2344025@donga.ac.kr` |
| 운영진 응답 지연 시 문의 | 교수 박종규 `pjk5401@dau.ac.kr` |
| 사용 결과 보고서 접수 | 교수 박종규 `pjk5401@dau.ac.kr` |

두 양식은 빈 HWP 원본만 Git에서 관리하며, 학생이 작성한 문서는 이메일로만 접수한다.

1. 학생이 안내 사이트에 접속한다.
2. 자격, 기본 사양, 신청 절차를 확인한다.
3. 신청서를 내려받고 작성한다.
4. DevWorks 운영진 이메일로 신청서를 제출한다.
5. Tailscale을 설치한다.
6. 신청 이메일과 동일한 인증 계정으로 로그인한다.
7. 운영진에게 받은 초대 링크를 열어 네트워크에 참여한다.
8. 운영진은 학번을 ID로 VM을 수동 생성한다.
9. 학생은 이메일로 생성 완료 알림을 받는다.
10. 학생은 Tailscale 연결 후 VM에 접속한다.
11. 학생은 서비스를 배포하고 `http://학번.dauswc.org`에서 확인한다.
12. 사용 종료 후 결과 보고서를 내려받아 작성한다.
13. 학생은 결과 보고서를 교수 이메일로 제출한다.

## 6. 콘텐츠 요구사항

- 각 문서는 학생이 해야 할 행동부터 명확히 제시한다.
- 명령어는 복사 가능한 코드 블록으로 제공한다.
- 운영체제별 차이가 있으면 Windows, macOS, Linux로 구분한다.
- 화면 이미지는 버전 변경으로 낡을 수 있으므로 텍스트 설명도 함께 제공한다.
- 확정된 담당자 이메일과 양식 파일명을 정확히 표시한다.
- VM 접속 명령은 운영 정보가 확정된 후 반영한다.
- 외부 링크에는 목적을 설명하고 공식 문서를 우선 사용한다.
- 초대 링크를 공유하지 말아야 한다는 주의사항을 표시한다.

## 7. 비기능 요구사항

- 정적 파일만으로 배포할 수 있어야 한다.
- 데이터베이스와 서버 측 애플리케이션을 요구하지 않아야 한다.
- 주요 절차를 모바일에서도 읽고 따라갈 수 있어야 한다.
- 첫 화면에서 전체 절차와 현재 준비물을 파악할 수 있어야 한다.
- 메뉴는 학습 순서와 동일하게 구성한다.
- 깨진 링크와 잘못된 명령어를 배포 전에 점검한다.

## 8. 보안 및 개인정보

- HTTP 운영 기간에는 개인정보를 입력받거나 전송하지 않는다.
- 저장소에 실제 학생 정보, 신청서, 비밀번호, 토큰을 저장하지 않는다.
- 빈 HWP 원본 양식만 공개 저장소에서 관리한다.
- 이메일 알림에는 VM 비밀번호나 인증 토큰을 포함하지 않는다.
- 학생이 배포하는 서비스에서 개인정보나 로그인을 처리하려면 HTTPS가 필요함을 안내한다.
- HTTPS 도입 전까지 이 사이트는 정보 제공용 정적 사이트로 제한한다.

## 9. 완료 기준

- 신규 학생이 문서만 보고 신청부터 서비스 주소 확인까지의 순서를 설명할 수 있다.
- 신청서 다운로드와 이메일 제출 경로가 명확하다.
- 결과 보고서의 다운로드, 제출 시점, 수신자가 명확하다.
- Tailscale 설치, 로그인, 초대 수락, 연결 확인 절차가 제공된다.
- VM 접속 및 최소 배포 예제가 정상 동작한다.
- 개인정보를 수집하는 폼이나 스크립트가 없다.
- 모바일과 데스크톱에서 핵심 콘텐츠를 확인할 수 있다.
