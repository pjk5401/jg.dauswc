## Unreleased

- 프로젝트 목적과 운영 흐름 문서화
- 기존 신청서 기준과 VM 기본 사양 정리
- Tailscale 설치 및 초대 절차 요구사항 정리
- HWP 신청서 및 사용 결과 보고서의 배치 경로 정의
- 교수 운영진과 VM 운영진의 역할 및 연락처 정의
- PDCA 운영 계획과 학기별 점검 방식 추가
- HTTPS 도입 및 신청 시스템 재검토를 장기 로드맵에 추가
- VitePress 기반 학생용 정적 안내 사이트 초안
- 신청, Tailscale, VM 접속, 서비스 배포, 결과 보고, FAQ 페이지
- HWP 신청서와 결과 보고서 다운로드 링크
- DevWorks 운영진을 신청 및 VM 운영의 기본 연락 창구로 변경
- Ubuntu Python 서버의 8080 포트 배포 예제 추가
- 서비스명을 `DAU Cloud Hub`로 변경
- 개발 및 정적 미리보기 서버의 기본 포트를 8080으로 변경
- Ubuntu VM용 백그라운드 시작·종료·배포 스크립트 추가

### 변경

- 웹 신청 및 승인 시스템 계획을 정적 안내 사이트로 변경
- 디스크 기본값을 1 GB에서 10 GB로 확정
