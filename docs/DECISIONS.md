# 주요 결정 기록

프로젝트의 방향이 바뀐 이유를 잊지 않기 위한 기록이다. 결정을 변경할 때는 기존 내용을 지우지 않고 새 항목을 추가한다.

## D-001: 웹 신청 및 승인 시스템 검토

- 일자: 2026-06-07
- 상태: 대체됨

초기에는 학생이 웹에서 VM을 신청하고 운영진이 승인 결과를 관리하는 서비스를 계획했다.

예정했던 주요 기능:

- 학생 및 관리자 로그인
- 기존 신청서의 웹 폼 전환
- 신청 상태와 승인 결과 조회
- 클라우드 서버 사양과 사용 기간 입력
- VM 생성 완료 알림

## D-002: 정적 안내 사이트로 범위 변경

- 일자: 2026-06-07
- 상태: 채택

현재 환경에서 HTTPS를 제공하지 못하므로 웹에서 이름, 학번, 연락처, 이메일, 로그인 정보 등을 처리하는 것은 적절하지 않다고 판단했다.

결정:

- 이메일 신청 방식을 유지한다.
- 웹은 개인정보를 수집하지 않는 정적 매뉴얼로 제한한다.
- 승인, VM 생성, 완료 알림은 기존 이메일 절차로 처리한다.
- 문자 등 비용이 발생하는 알림은 사용하지 않는다.

영향:

- 데이터베이스, 인증, 관리자 화면, 신청 상태 조회는 만들지 않는다.
- 사이트 운영과 보안 부담이 줄어든다.
- 신청 상태의 통합 조회는 장기 과제로 남는다.

## D-003: 문서형 Quick Start 구조 사용

- 일자: 2026-06-07
- 상태: 채택

학생이 순서대로 따라야 할 단계가 많으므로 일반 홍보형 랜딩 페이지보다 문서형 사이트가 적합하다.

결정:

- API 문서와 유사한 좌측 탐색 구조를 사용한다.
- 내용은 API 레퍼런스가 아니라 학생 행동 중심의 Quick Start로 작성한다.
- VitePress를 우선 구현 후보로 사용한다.

## D-004: VM 신청 기본값

- 일자: 2026-06-07
- 상태: 채택

클라우드 서버 신청의 기본값:

- 메모리 1 GB
- 디스크 10 GB
- 신청일부터 3개월
- 무기한 사용 요청 가능
- VM ID는 신청자의 학번

그 외 CPU 및 운영체제 등은 운영 정책의 기본값을 사용한다.

## D-005: 학생 서비스 주소

- 일자: 2026-06-07
- 상태: 채택

학생이 VM에 서비스를 배포하면 `http://학번.dauswc.org` 형식으로 확인한다. 안내 사이트는 운영자의 교번을 사용한 `http://241110.dauswc.org`에 배포할 예정이다.

HTTP 환경에서는 개인정보, 인증정보 또는 민감한 데이터를 처리하는 서비스를 배포해서는 안 된다는 안내를 제공한다.

## D-006: Tailscale 연결 절차

- 일자: 2026-06-07
- 상태: 채택

학생은 Tailscale을 설치하고 인증 제공자를 통해 로그인한 뒤 운영진의 초대 링크를 수락해야 한다. 신청에 사용한 이메일과 동일한 계정을 사용하는 것을 기본 안내로 한다.

초대 링크는 공개 문서에 게시하지 않고 학생에게 개별 전달한다.
