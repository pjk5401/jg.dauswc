# 장기 개선 로드맵

로드맵은 확정 일정이 아니라 우선순위와 선행 조건을 관리하기 위한 문서다. 학기 시작 시 운영 여건에 맞게 조정한다.

## Phase 1: 안내 사이트 구축

목표: 현재 이메일 신청 절차를 정확하고 읽기 쉬운 문서로 제공한다.

- VitePress 프로젝트 구성
- 첫 이용자를 위한 Quick Start 작성
- 신청서 다운로드와 작성 예시 제공
- Tailscale 설치 및 초대 수락 안내
- VM 접속 및 최소 서비스 배포 안내
- FAQ와 문의 방법 제공
- `http://241110.dauswc.org` 배포

완료 조건:

- 테스트 사용자가 문서만 보고 전체 흐름을 수행한다.
- 개인정보를 수집하는 기능이 없다.
- 모바일과 데스크톱에서 핵심 문서를 확인한다.

## Phase 2: 문서 품질과 운영 개선

목표: 실제 문의와 실패 사례를 문서 개선으로 연결한다.

- 학기별 문의 유형 기록
- 운영체제별 Tailscale 화면 보강
- 신청서 누락 사례와 올바른 예시 추가
- 배포 예제 확대
- 링크 검사와 정적 빌드 검증 자동화
- GitHub Issues 또는 Discussions를 활용한 문서 오류 접수 검토

## Phase 3: HTTPS 도입

목표: 안내 사이트와 학생 서비스의 전송 보안을 확보한다.

검토 항목:

- `*.dauswc.org` 와일드카드 인증서
- DNS-01 방식 인증서 발급 가능 여부
- 리버스 프록시와 인증서 자동 갱신
- 학생 VM별 HTTPS 제공 구조
- HTTP에서 HTTPS로의 리디렉션
- 기관 네트워크 및 보안 정책

HTTPS를 도입해도 비밀번호나 개인정보를 저장소에 기록하지 않는다.

## Phase 4: 신청 프로세스 재검토

선행 조건:

- HTTPS가 안정적으로 제공된다.
- 개인정보 처리 책임과 운영 정책이 정해진다.
- 인증 방식과 관리자 권한 모델이 정해진다.
- 데이터 보관 및 파기 기준이 정해진다.

검토 가능한 기능:

- 웹 신청서
- 신청 상태 조회
- 관리자 승인, 반려, 보완 요청
- 이메일 알림 자동화
- VM 생성 완료 기록
- 사용 종료 7일 전 알림
- 감사 기록

자동화보다 개인정보 최소 수집과 운영 가능성을 먼저 검증한다.

## 보류 항목

- VM 자동 생성
- 문자 메시지 알림
- 공개 Tailscale 초대 링크
- HTTP 환경에서의 로그인 또는 개인정보 수집
