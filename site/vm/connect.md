# VM 접속

운영진이 VM 생성을 완료하면 이메일로 알려드립니다. 완료 알림을 받기 전에는 접속할 수 없습니다. ___VM 생성까지는 최대 1~2일이 걸릴 수 있습니다.___


## 접속 전 확인

- VM 생성 완료 이메일을 받았습니다.
- 학생 PC에서 Tailscale이 연결되어 있습니다.
- VM ID는 본인의 학번입니다.

## 할당받은 클라우드 주소 확인

1. 작업 표시줄에서 아래 그림과 같이 Tailscale 아이콘을 우클릭합니다.

![Windows 작업 표시줄의 Tailscale 아이콘](/img/image.png)

2. 메뉴의 [Network devices -> My devices]를 클릭합니다.
3. [My devices]에서 나오는 기기를 선택하면 그림과 같이 클립보드에 IP가 자동으로 복사됩니다. 일반적으로 100.x.x.x 형태입니다. 이 주소가 여러분이 할당받은 클라우드 VM의 주소입니다.

![VM IP](/img/ip.png)

## SSH 접속 형식

일반적인 접속 형식은 다음과 같습니다.

```bash
ssh {학번}@{Tailscale IP}
```

```bash
ssh 241110@100.101.163.40
```

::: info 중요
`최초 비밀번호`는 `학번`과 같습니다. 처음 로그인한 즉시 `passwd` 명령으로 비밀번호를 변경한 뒤 VM을 사용하세요.
:::

## SSH가 무엇인지 모를 때

SSH는 원격에서 컴퓨터를 제어하기 위한 보안 네트워크 프로토콜입니다. 여러분이 AWS EC2를 대여하더라도 SSH를 사용하여 접속하게 됩니다. VSCode에서 SSH를 이용하여 원격 서버에 접속하는 방법 등을 학습한 후 사용하시기 바랍니다.
