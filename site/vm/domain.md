# 학번 도메인으로 확인

학생 서비스 주소는 학번을 기준으로 생성됩니다.

```text
http://{학번}.dauswc.org
```

## 예시

학번 또는 교번이 `241110`인 경우 [서비스 배포](/vm/deploy)의 예제 서비스를 배포한 후 주소창에 다음과 같이 입력합니다.

```text
http://241110.dauswc.org
```

![예제 배포 화면](/img/deploy.png)

## 접속되지 않을 때

1. VM 내부에서 서비스가 실행 중인지 확인합니다.
2. 서비스가 `8080` 포트를 사용하는지 확인합니다.
3. 서비스 실행 시 `--bind 0.0.0.0` 옵션을 사용했는지 확인합니다.
4. 도메인의 학번을 정확히 입력했는지 확인합니다.
5. 위 항목이 모두 정상이라면 DevWorks 운영진에게 DNS와 프록시 연결 상태를 문의합니다.
