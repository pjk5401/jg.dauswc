# 신청 전 확인

VM 신청 전에 기본 제공 사양과 사용 기간을 확인하세요.

## 기본 VM 사양

| 항목 | 기본값 |
| --- | --- |
| 메모리 | 1 GB |
| 디스크 | 10 GB |
| VM ID | 신청자의 학번 |
| 사용 시작일 | 신청일 |
| 사용 종료일 | 신청일로부터 3개월 |
| 운영체제 | Ubuntu Linux |

기본값과 다른 구성이 필요하다면 **신청서의 활용 목적과 프로젝트 내용을 구체적으로 작성**하세요. 실제 제공 가능 여부는 운영진 검토 결과에 따라 달라질 수 있습니다.

## 무기한 사용

무기한 사용이 필요한 경우 신청서에 별도로 요청할 수 있습니다. 서버 자원을 계속 사용하는 사유를 구체적으로 작성하세요.

::: warning
무기한 요청은 자동 승인되지 않습니다. 운영 상황과 활용 목적을 검토한 후 결정됩니다.
:::

## 서비스 주소

VM에 배포한 서비스는 다음 형식의 주소로 확인합니다.

```text
http://{학번}.dauswc.org
```

예를 들어 학번 또는 교번이 `241110`이면 다음 주소를 사용합니다.

```text
http://241110.dauswc.org
```

현재 HTTP 환경에서는 로그인, 개인정보, 결제정보 등 민감한 정보를 처리하는 서비스를 운영하지 마세요.
