# 이메일로 신청하기

작성한 HWP 신청서는 DevWorks 운영진에게 이메일로 제출합니다. 학교 이메일을 사용할 필요는 없으며, Tailscale 연동이 편리한 Gmail 계정을 권장합니다.

</div>

## 권장 메일 제목

```text
[클라우드 사용 신청] 학번_이름
```

예시:

```text
[클라우드 사용 신청] 20260000_홍길동
```

## 제출 전 점검

- 신청서의 필수 항목을 모두 작성했나요?
- `클라우드 서버` 항목을 선택했나요?
- 프로젝트 목적과 내용을 구체적으로 작성했나요?
- 필요한 사용 기간을 확인했나요?
- 신청서 파일을 첨부했나요?

::: warning
Tailscale 초대 링크, 비밀번호, 접속 토큰 등은 신청 메일이나 질문 메일에 포함하지 마세요.
:::

신청서 제출 후에는 [Tailscale 설치](/tailscale/install)를 진행하세요.
