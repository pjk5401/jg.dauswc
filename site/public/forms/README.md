# 양식 파일 배치 안내

이 폴더에 학생이 내려받을 빈 HWP 원본 양식을 넣습니다.

필수 파일:

```text
vm-application.hwp
vm-usage-report.hwp
```

- `vm-application.hwp`: VM 신청서
- `vm-usage-report.hwp`: 사용 결과 보고서

주의사항:

- 파일명은 위 이름을 그대로 사용합니다.
- 학생이 작성한 파일이나 개인정보가 포함된 문서는 넣지 않습니다.
- 양식을 교체한 뒤에는 실제 다운로드와 HWP 열기를 확인합니다.
- 양식의 담당 이메일이 사이트 연락처와 일치하는지 확인합니다.
