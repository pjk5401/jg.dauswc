# 문제 해결 및 FAQ

## 신청서를 어디로 보내나요?

신청서, Tailscale, VM 접속, 서비스 운영 문제 등은 DevWorks 운영진 `2344025@donga.ac.kr`로 문의합니다.

DevWorks 운영진의 응답이 늦거나 문제가 해결되지 않으면 교수 박종규 `pjk5401@dau.ac.kr`에게 문의합니다.

사용 결과 보고서는 교수 박종규 `pjk5401@dau.ac.kr`에게 제출합니다.

## Tailscale 초대가 오지 않습니다

- 신청서의 이메일 주소가 정확한지 확인하세요.
- 스팸 메일함을 확인하세요.
- 운영진이 신청서를 확인하고 초대를 발송할 시간이 필요할 수 있습니다.
- 1~2일이 지나도 오지 않으면 학번과 이름을 적어 DevWorks 운영진에게 문의하세요.
- DevWorks 운영진의 응답이 없으면 교수에게 문의하세요.

## 다른 계정으로 Tailscale에 로그인했습니다

현재 계정에서 로그아웃한 뒤 신청서에 작성한 이메일 계정으로 다시 로그인하세요. 초대가 이미 다른 계정에 연결되었다면 운영진의 확인이 필요합니다.

## 초대 링크가 작동하지 않습니다

링크가 만료되었거나 이미 사용되었을 수 있습니다. 링크를 다른 사람에게 전달하지 말고 DevWorks 운영진에게 재발급을 요청하세요.

## VM 생성 완료 메일을 받았지만 접속할 수 없습니다

다음을 확인하세요.

- Tailscale 상태가 `Connected`인지
- 신청 이메일과 같은 계정으로 로그인했는지
- 접속 주소와 계정명을 정확히 입력했는지
- 학교 또는 공용 네트워크가 연결을 제한하는지

문의 시 오류 메시지나 캡쳐 화면을 함께 보내면 확인에 도움이 됩니다. 비밀번호와 개인 키는 보내지 마세요.

## 도메인에서 서비스가 보이지 않습니다

- VM 내부에서 서비스가 실행 중인지 확인하세요.
- `curl http://localhost:8080`으로 응답을 확인하세요.
- 학번 도메인을 정확히 입력했는지 확인하세요.
- 운영진이 지정한 `8080` 포트를 사용했는지 확인하세요.
- 서버 실행 시 `--bind 0.0.0.0` 옵션을 사용했는지 확인하세요.

## 사용 기간을 연장하고 싶습니다

기존 사용 기간이 끝나기 전에 DevWorks 운영진에게 연장 사유와 필요한 기간을 문의하세요. 연장은 자동으로 승인되지 않습니다.
