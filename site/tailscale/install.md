# Tailscale 설치 및 로그인

Tailscale은 학생 PC와 할당된 VM을 안전한 Private Network로 연결하여 여러분이 원격에서 작업할 수 있도록 하는 프로그램입니다. (여러분 PC와 클라우드 PC를 같은 네트워크로 묶음)

## 1. 프로그램 설치

[Tailscale 공식 다운로드 페이지](https://tailscale.com/download)에서 사용 중인 운영체제에 맞는 버전을 설치하세요.

### Windows

1. 공식 설치 파일을 내려받습니다.
2. 설치 프로그램을 실행합니다.
3. 작업 표시줄에서 아래 그림과 같이 Tailscale 아이콘을 확인합니다.

![Windows 작업 표시줄의 Tailscale 아이콘](/img/image.png)

### macOS

1. 공식 안내에서 권장 설치 방식을 확인합니다.
2. Tailscale을 실행합니다.
3. 메뉴 막대에서 Tailscale 아이콘을 확인합니다.

### Linux

배포판에 맞는 공식 설치 안내를 따르세요. 리눅스 버전의 안내는 생략합니다.

## 2. 로그인

Tailscale은 Google, Microsoft 등 인증 제공자를 이용해 로그인합니다.

1. `Log in` 또는 `Sign in`을 선택합니다.
2. VM 신청서에 작성한 이메일과 동일한 계정을 선택합니다.
3. 브라우저 인증을 완료합니다.

::: warning 계정을 꼭 확인하세요
다른 개인 계정으로 로그인하면 운영진의 초대를 정상적으로 사용할 수 없을 수 있습니다.
:::

로그인을 마쳤다면 운영진의 [초대 링크 수락](/tailscale/invitation)을 진행합니다. 아직 초대 링크가 도착하지 않았다면 잠시만 기다려주세요. ___초대 링크 발송까지는 최대 1~2일이 걸릴 수 있습니다.___
