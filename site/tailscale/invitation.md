# 초대 링크 수락

운영진의 Tailscale 네트워크에 참여하려면 개별 초대 링크를 수락해야 합니다. 아직 초대 링크가 도착하지 않았다면 잠시만 기다려주세요. ___초대 링크 발송까지는 최대 1~2일이 걸릴 수 있습니다.___


## 진행 방법

1. 운영진이 보낸 초대 안내를 확인합니다.
2. 초대 링크를 본인 브라우저에서 엽니다.
3. 신청서에 작성한 이메일과 동일한 계정인지 확인합니다.
4. 참여 또는 승인 버튼을 선택합니다.
5. Tailscale 프로그램으로 돌아갑니다.

::: danger 초대 링크를 공유하지 마세요
초대 링크는 본인에게만 전달된 정보입니다. 다른 학생이나 공개 채팅방에 전달하지 마세요.
:::

## 초대가 보이지 않을 때

- 스팸 메일함을 확인합니다.
- 신청서에 작성한 이메일 주소를 확인합니다.
- Tailscale 로그인 계정이 신청 이메일과 같은지 확인합니다.
- 링크가 만료되었거나 작동하지 않으면 DevWorks 운영진에게 재발급을 요청합니다.

초대를 수락한 뒤 [연결 상태 확인](/tailscale/check-connection)으로 이동하세요.
